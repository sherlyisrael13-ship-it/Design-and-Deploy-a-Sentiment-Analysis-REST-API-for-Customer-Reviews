💬 Sentiment Analysis Prediction System
🤖 NLP Model Served via FastAPI on Cloud Run
🧠 Project Overview

This project provides a cloud-native solution for real-time text sentiment classification, predicting whether text is Positive, Negative, or Neutral.

It utilizes a Custom ML Model (Python-based) embedded within a FastAPI backend, deployed as a serverless container on Google Cloud Run. This architecture ensures scalability, high performance, and cost-efficiency for processing high volumes of text data.

⚙️ Tech Stack & Deployment

Component	Technology	Role
Backend/API	FastAPI	High-speed RESTful inference service.
Model Hosting	Google Cloud Run	Serverless, autoscaling container deployment.
Model	Custom ML Model (Python)	Classification logic.
Frontend	Custom Web Client (UI)	User input and display interface.
🚀 Key Features & Performance

Serverless: Full service deployed on Cloud Run for managed, elastic scaling.

High Performance: Achieved a competitive Accuracy of 91.5% and an F1-Score of 0.898.

API Endpoint: Access predictions via a single, low-latency API endpoint.
